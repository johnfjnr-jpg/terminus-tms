   table that was overprinting. The grid track is now measured.
3. The first `label-input` injection moved the input sideways under clear space and came back
   SILENT. I measured it (label text bottom 191, input top 199) before reading the silence as a
   gap, then rewrote the injection.

## 6. Positions taken where the rulings were silent (all revisitable)

1. **With Split WHT off, an OPEX month stays ONE line** (spec 8.1). Two lines at 10% gross-up give
   322,020.85 against T20's 322,020.86, so a split at one rate would move an existing figure.
2. **Line WHT is `round_half_up(invoice x rate)` in both modes.** That is what the built engine
   and T20 already do. My first draft wrote `invoice - net` for gross-up, and I corrected it
   before committing.
3. **GST is per invoice line**, on the line's invoice (spec 8's "per invoice line").
4. **A split OPEX service line below zero is refused** with a clear message. It needs unusual
   admin margins, for example a 99% hardware margin at 12 months. The spec now lists this in
   section 13 as an implementation position.
5. **The start year (S):**
   - **Engine:** an S past the term's last year is not refused, because the ladder prices every
     term from the same inputs, and the formula already gives no increase there.
   - **Screen:** choosing a shorter term pulls S back inside it, so the select and the engine
     read one value.
   - **Rate 0:** the select is disabled, not hidden, which keeps the layout steady.
   - **12 months:** the select is not offered, and a typed rate shows "A 12-month term has no
     year 2, so the escalator has no effect."
6. **The escalator's placeholder is now "0", not "none"**, under the estate's placeholder-format
   rule (a value in the field's format, never prose).
